# Research: 10 HTML Tags

| Tag | What it does | When to use |
|---|---|---|
| `<header>` | Page/section top area | Logo, title, nav bar |
| `<nav>` | Navigation links | Menu, links group |
| `<main>` | Main content area | Page's primary content |
| `<section>` | Grouped content block | Divide content like chapters |
| `<article>` | Self-contained content | Blog post, news article |
| `<aside>` | Side content | Sidebar, related links |
| `<footer>` | Bottom of page | Copyright, contact info |
| `<figure>` | Image with caption | Photo + description |
| `<time>` | Date/time display | "Posted on May 6" |
| `<mark>` | Highlighted text | Search results highlight |
